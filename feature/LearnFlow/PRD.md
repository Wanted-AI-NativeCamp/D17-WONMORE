# LearnFlow PRD v0.4

- 상위 브랜드: WONMORE
- 서비스: LearnFlow
- 버전: v0.4 (변경 이력은 맨 아래 참고)
- 날짜: 2026-11-06
- 목표: 개인 개발 MVP (원티드 AI 네이티브 커리어 캠프 2기 교육생 대상)
- 기술 스택: **Python 3.11+ · Streamlit 1.66** (로컬 실행 `localhost:8501`)
- 핵심 결정: **원본 HTML 수업 자료를 구간(section) 단위로 재구성하고, 캠프 일정(캘린더) 위에서 그날 수업을 찾아 구간을 따라가며 진행 상황·어려움·결과물을 기록한다.**

## 1. 제품 정의
LearnFlow는 매일 받는 HTML 수업 자료를 구간별로 나눠 다시 보여주고, **캠프 일정 캘린더**에서 그날 수업을 바로 열며, 구간마다 **체크인(잘 따라가고 있나요?)·학습 기록·과제 결과물**을 남겨 Day별로 다시 확인하는 Streamlit 앱이다. 같은 수업 화면을 **수강생 모드(학습 중심)**와 **관리자 모드(관리 중심)**로 나눠 볼 수 있다.

### 문제 가설
- 수업 자료 하나가 길어서(6~11개 구간, 최대 약 350KB) 지금 어디쯤인지 알기 어렵다.
- 지난 수업 자료를 찾고, 보던 위치로 돌아가기 번거롭다.
- 학습 중 막힌 지점과 해결 방법을 구간과 연결해서 남기기 어렵다.
- 캠프 일정(구간·마감·프로젝트 기간)과 그날 수업이 따로 놀아 흐름을 놓친다.

### MVP 성공 기준
학습 캘린더에서 날짜를 골라 그날 수업을 열고, 구간별 진행 현황으로 이동하며 학습하고, 구간마다 체크인·기록을 남기고, 앱을 다시 켰을 때 보던 위치와 기록이 그대로 있다.

## 2. 대상 사용자와 모드
- **사용자는 1명(본인)이다.** 로컬에서 혼자 실행하는 것을 전제로 한다. 로그인은 없다.
- 수업 화면에는 두 가지 **역할 모드**가 있다 (저장값 `prefs.role`).
  - **수강생 모드**(기본): 구간별 진행 현황(내 상태) · 체크인 · 내 체크인 기록 · 조별 편성(참석/불참) · 본문 · 학습 기록 남기기
  - **관리자 모드**: 구간별 진행 현황(수강생 인원 숫자) · 본문
  - 두 모드의 세부 차이는 추후 정리한다 (§13).
- 교육 모아보기에는 **보기 모드**가 따로 있다 (저장값 `prefs.mode`).
  - 차근차근 학습(`beginner`): Day 카드 → 수업 화면에서 구간을 하나씩
  - 빠르게 둘러보기(`advanced`): 페이지 이동 없이 Day 토글 → 구간 토글로 흐름만 훑기
- **숙련자 모드는 만들지 않는다**(추후 고려).

## 3. 핵심 정책
1. **원본 파일은 수정하지 않는다.** `Data/` 원본 HTML은 읽기만 한다. 교육 자료 업로드(F20)는 **새 파일만 추가**하고, 그날 자료가 이미 있으면 덮어쓰지 않고 거절한다.
2. **보여주는 방식은 바꾸되 내용은 지어내지 않는다.** 구간 나누기·단계 탭·레이아웃·디자인은 허용한다. 미리보기·요약·탭 이름은 **원본 제목·소제목·본문을 잘라서만** 쓴다.
3. **구간 = 원본의 `<section id>` 단위.** 구간 제목은 원본 `<h2>`를 그대로 쓴다.
4. **기록은 Day와 구간에 연결한다.** 하나의 구간에 여러 기록을 남길 수 있다. 프로젝트 기간 기록은 `section_id = "project"`.
5. **원본 메뉴(`<nav class="toc">`)와 원본 스크립트는 화면에서 쓰지 않는다.**
6. **개인 데이터는 로컬 파일에만 저장한다.** `app/.userdata/learnflow.v1.json`(+ `backups/`, `thumbnails/`). 읽기·쓰기는 `lib/storage.py`에서만 한다.
7. **수업 자료·분석 결과·개인 데이터는 GitHub에 올리지 않는다.** `Data/`, `lessons.generated.json`, `.userdata/`는 `.gitignore`. 재배포 권한 확인 전에는 공개 배포하지 않는다. (배포하면 저장 파일을 모든 방문자가 공유하게 되므로 저장 방식을 다시 설계해야 한다)
8. **삭제는 확인창을 거쳐 한 건씩만.** 일괄 삭제·초기화 기능은 만들지 않는다.

**F15 학습 캘린더 세부**
- **F15-1 일별(기본):** `‹ mm/dd ›`(대주제와 같은 가운데 기준) + `[오늘 ↶]`(오른쪽 바깥) · 요일·D번호·[오늘] → `[태그]` → 대주제(h2 28px) → 소제목(h3, `D17 · 수업 제목`) → 구간 완료율 → **이 날의 학습 목록**(왼쪽 목록 : 오른쪽 미리보기 = **1 : 2**, 미리보기 높이 = 목록 높이, 미리보기 = 원본 소제목 5개 + 본문 앞 180자 + [학습하기]) → 과제 뽐내기(F17). 선택 안 된 목록 글자는 회색.
- **F15-2 월별:** 왼쪽 7 : 오른쪽 3. 왼쪽 흰 카드 = `‹ n월 › [오늘 ↶]` + 월~금 캘린더(주마다 **같은 구간을 한 블록으로 합침**, `[태그] 주제`는 그 달 구간 첫 블록에만, 줄마다 높이 맞춤, 블록 누르면 구간 선택). 오른쪽 = 기간·수업일 + 날짜 버튼(회색 트랙, 2칸 격자, 칸 폭 꽉) + 그날 수업 카드(`내 체크인 기록`은 토글). **1100px 이하:** 오른쪽이 캘린더 아래로. **767px 이하:** 캘린더 대신 그 달 구간 카드 목록 + 캘린더 카드 안 구간 요약.
- **F15-3 전체 일정:** 10월~1월 4열 구간 카드(흰 카드) + 아래 기간·수업일 + 날짜 토글(767px 이하는 월별과 같은 날짜 버튼) + 그날 수업 카드.
- 공통: 지나간 날·이벤트·휴무일 글자 `#767D88`, 오늘 태그 보라 `#6541F2`, 선택 구간 = 배너 그라데이션 배경 + 보라 테두리.

| 화면 | 주소 | 구성 |
|---|---|---|
| 학습 캘린더 (홈) | `/` | 배너(소개 + [＋ 교육 자료 추가하기] [＋ 내 기록 추가하기]) → 기간·캠프 제목·보기 전환 → 캘린더(F15) → 안내 문구 → 그날 수업 카드(전체 일정만) |
| 교육 모아보기 | `?page=lessons` | 보기 모드 → 이어보기 → Day 그룹 카드(F1/F16) 또는 Day 토글(F13) |
| 수업 화면 | `?day=D17&sec=am` | **왼쪽 3**: 구간별 진행 현황(F24) → (수강생) 체크인 → D? 체크인 기록 → 조별 편성 / (관리자) 끝. **오른쪽 7**: `[수강생\|관리자]` ··· `[← 이전 구간] [다음 구간 →]` → `D17 · 수업 제목` → 구간 제목·상태 → 본문(단계 탭) → (수강생) 학습 기록 남기기 |
| 프로젝트 기록 | `?project=D12` | D11~D15 날짜 선택 → 기록 남기기 / 기록 목록 |
| 학습 기록 | `?page=records` | 기록 수 요약 + [＋ 기록 추가하기] + 탭 3개(F19) |
| 관리자 | `?page=admin` | 조 편성(차수·조 이름·조원 추가 / 차수별 목록 수정·삭제) · 불참 관리(날짜·불참자) |

## 6. 사용자 흐름
- **오늘 수업:** 학습 캘린더(일별, 오늘) → 이 날의 학습 목록에서 구간 미리보기 → [학습하기] → 수업 화면 → 본문·단계 탭 따라 하기 → 체크인 → 다음 구간
- **지난 수업 찾기:** 월별/전체 일정에서 구간 → 날짜 → 그날 카드 [학습하기], 또는 교육 모아보기 Day 카드
- **기록:** 수업 화면 체크인·학습 기록 / 배너 [＋ 내 기록 추가하기] → 학습 기록 페이지 탭에서 모아 보기
- **결과물:** 일별 보기 과제 뽐내기 + 타일 → 배포 링크 등록
- **관리:** ⚙ 관리자에서 차수별 조 편성 → 수업 화면(수강생 모드) 조별 편성에서 그날 참석/불참 → 관리자 모드 진행 현황으로 구간별 인원 확인

## 9. 디자인

- **선택 상태:** 배너 그라데이션 배경 + 보라 단색 테두리 `#8364FF`. hover·포커스 테두리도 보라.

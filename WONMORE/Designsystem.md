# WONMORE 디자인 시스템

- 기준: 원티드 브랜드센터 + 원티드 몽타주(Montage) 디자인 시스템에서 **우리 서비스에 필요한 부분만** 추림
- 출처: [브랜드센터](https://www.wanted.co.kr/brandcenter/) · [Montage Foundations](https://montage.wanted.co.kr/docs/foundations)
- 확인일: 2026-11-05
- 표기: **[원티드]** 공식 값 그대로 / **[WONMORE]** 원티드 문서에 값이 없어 팀이 정한 값

## 디자인 키워드
Soft, Friendly, Clean, Organized, Colorful but Minimal.

## 1. 컬러

브랜드센터 기준 값이며 임의로 바꾸지 않는다.

| Violet | `#8364FF` | 4.0:1 ⚠️ | 숙련자 모드 포인트 (큰 글씨·아이콘·테두리·배경) |
| Pink | `#FF8EFF` | 2.0:1 ❌ | 공동 학습 아카이브 장식 (글자 금지) |

| 토큰 | HEX | 흰 배경 대비 | 쓰는 곳 |

| `--warning-text` | `#B85A20` | 4.6:1 | 경고 글자 (배경 `#FFF1E6` 위 4.2:1이므로 14px 이상·굵게) |

## 2. 타이포그래피
- 글꼴: **Pretendard** (몽타주 기본 글꼴 Pretendard JP의 한국어·영어 버전) [원티드]
  - 웹: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`
  - 대체 글꼴: `Pretendard, -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 크기·줄 간격·자간: 몽타주 스케일에서 쓰는 단계만 [원티드]. 굵기는 몽타주 문서에 값이 없어 팀이 정함 [WONMORE].

| 용도 | 몽타주 단계 | 크기 / 줄 간격 | 자간 | 굵기 |
|---|---|---|---|---|
| 페이지 제목 (홈 히어로, Day 제목) | Title 2 | 28 / 38px | -0.0236em | 700 |
| 구간 제목 (원본 h2) | Heading 1 | 22 / 30px | -0.0194em | 700 |
| 카드 제목, 소제목 (원본 h3) | Headline 1 | 18 / 26px | -0.002em | 600 |
| 수업 본문 | Body 1 Reading | 16 / 26px | 0.0057em | 400 |
| UI 본문 (기록, 설명) | Body 2 Normal | 15 / 22px | 0.0096em | 400 |
| 버튼, 탭, 태그 | Label 1 Normal | 14 / 20px | 0.0145em | 600 |
| 보조 정보 (날짜, 개수) | Caption 1 | 12 / 16px | 0.0252em | 400 |

- 3단계 위계: 제목(Black `#14191E`) · 본문(`#252832`) · 보조정보(`#5F6673`).
- 코드: `ui-monospace, "SF Mono", Consolas, monospace` 14px.

## 3. 간격·그리드 [원티드]
- 8px 단위를 기본으로 하고, 필요하면 4px 배수를 쓴다. 시각 보정이 필요할 때만 2px.
- 칸 사이 간격(gutter): 20px.
- 화면 너비 기준(breakpoint): 우리 서비스는 몽타주 기준 중 **768px / 1200px** 두 개만 쓴다.

| 너비 | 구분 | 콘텐츠 최대 너비 |
|---|---|---|
| 767px 이하 | 모바일 | 전체 너비 (좌우 여백 16px) |
| 768~1199px | 태블릿·작은 창 | 전체 너비 (좌우 여백 24px) |
| 1200px 이상 | 데스크톱 | 1100px [원티드] |

## 4. 모양·그림자
- 모서리 [WONMORE] (몽타주 문서에 값 없음): 카드 20px / 버튼·입력창 12px / 태그 999px
- 그림자: 몽타주 단계 이름을 따르되, 우리는 두 단계만 쓴다. 값은 [WONMORE].

| 몽타주 단계 | 쓰는 곳 | 값 |
|---|---|---|
| 1 XSmall | 카드 hover | `0 1px 2px rgba(20,25,30,0.06)` |
| 3 Medium | 드롭다운, 팝오버, 다이얼로그 | `0 4px 16px rgba(20,25,30,0.10)` |

- 기본 카드는 그림자 없이 얇은 테두리(`#E6E8EF`)로 구분한다.

## 5. 공통 규칙
| 항목 | 적용 규칙 |
|---|---|
| 기본 배경 | 화이트 또는 아주 밝은 뉴트럴 그레이 |
| 포인트 컬러 | 화면별 지정된 한 가지 컬러 계열 사용 (§1) |
| 주요 CTA | 화면별 포인트 컬러의 진한 단색 (대비 4.5:1 이상) |
| 선택 상태 | 연한 포인트 배경 + 진한 텍스트 |
| 카드 | 흰색 배경, 얇은 테두리, 20px 둥근 모서리 |
| 그림자 | 기본 없음, 떠 있는 요소만 §4 단계 사용 |
| 그라데이션 | 아이콘, 작은 일러스트, 헤더 장식 등에 제한 |
| 태그 | 기본 뉴트럴, 선택된 항목만 컬러 강조 |
| 상태 표현 | 색상에만 의존하지 않고 텍스트·아이콘 병행 |
| 접근성 | 글자 대비 4.5:1 이상, 파스텔 배경 위 작은 글자 지양, 대비 부족 색(⚠️·❌)은 글자에 쓰지 않음 |

- **공통 컴포넌트:** 버튼·카드·입력창 등 반복되는 UI는 동일한 규격을 사용한다.
- **컬러 일관성:** 화면별 포인트 컬러는 해당 화면의 주요 행동과 선택 상태에만 적용한다.
- **반응형 대응:** 데스크톱을 우선 설계하되, 화면 크기에 따라 콘텐츠가 잘리지 않도록 구성한다.
- **디자인 협업:** 공통 스타일 변경 시 디자인팀과 합의하고 개발팀에 공유한다.

## 6. 문구 원칙 [원티드]
- **부드럽지만 명확하게:** 돌려 말하지 않고, 다정한 말투로 쓴다.
- **자신감 있는 목소리로:** "~것 같아요"보다 확실하게 말한다.
- **듣는 이의 입장을 고려하여:** 사용자를 다른 사람과 비교하지 않는다.
- **간결하고 꾸밈없이:** 40자가 넘는 문장은 나눈다. 이모지·유행어는 아껴 쓴다.
- 브랜드 표기: 서비스 이름은 붙여 쓴다(WONMORE, LearnFlow). 원티드 로고·심볼은 WONMORE 화면에 쓰지 않는다.

## 7. 애니메이션
| 요소 | 적용 방식 |
|---|---|
| 버튼 | Hover 시 색상·밝기 부드럽게 전환 |
| 카드 | Hover 시 미세한 상승 또는 테두리 강조 |
| 화면 진입 | Fade-in 및 가벼운 Slide-up |
| 모달·드롭다운 | 부드러운 열림·닫힘 전환 |
| 선택 상태 | 배경색·테두리 색상 자연스럽게 전환 |
| 로딩 | 스켈레톤 또는 부드러운 로딩 인디케이터 |

- **전환 시간:** 기본 150~300ms
- **움직임:** 자연스러운 Ease-out 중심
- **성능:** CSS Transition·Animation 우선 사용
- **접근성:** `prefers-reduced-motion` 설정 존중

## 디자인 키워드
Soft, Friendly, Clean, Organized, Colorful but Minimal. 

## 디자인 시스템
팀 공통 디자인 규칙 확정안

| 항목 | 적용 규칙 |
|---|---|
| 기본 배경 | 화이트 또는 아주 밝은 뉴트럴 그레이 |
| 포인트 컬러 | 화면별 지정된 한 가지 컬러 계열 사용 |
| 주요 CTA | 화면별 포인트 컬러의 진한 단색 적용 |
| 선택 상태 | 연한 포인트 배경 + 진한 텍스트 |
| 카드 | 흰색 배경, 얇은 테두리, 12~20px 둥근 모서리 |
| 그림자 | 없거나 매우 약하게 사용 |
| 그라데이션 | 아이콘, 작은 일러스트, 헤더 장식 등에 제한 |
| 타이포그래피 | 제목·본문·보조정보 3단계 위계, 차콜·중립 회색 사용 |
| 태그 | 기본 뉴트럴, 선택된 항목만 컬러 강조 |
| 상태 표현 | 색상에만 의존하지 않고 텍스트·아이콘 병행 |
| 레이아웃 | 최대 너비 통일, 8px 단위 간격 시스템 |
| 접근성 | 충분한 명도 대비 확보, 파스텔 배경 위 작은 글자 지양 |

#### 추가 작업 원칙

- **공통 컴포넌트:** 버튼·카드·입력창 등 반복되는 UI는 동일한 규격을 사용한다.
- **컬러 일관성:** 화면별 포인트 컬러는 해당 화면의 주요 행동과 선택 상태에만 적용한다.
- **반응형 대응:** 데스크톱을 우선 설계하되, 화면 크기에 따라 콘텐츠가 잘리지 않도록 구성한다.
- **애니메이션:** 부드러운 전환과 마이크로 인터랙션을 적용하되 과도한 움직임은 지양한다.
- **디자인 협업:** 공통 스타일 변경 시 디자인팀과 합의하고 개발팀에 공유한다.

#### 애니메이션 가이드

| 요소 | 적용 방식 |
|---|---|
| 버튼 | Hover 시 색상·밝기 부드럽게 전환 |
| 카드 | Hover 시 미세한 상승 또는 테두리 강조 |
| 화면 진입 | Fade-in 및 가벼운 Slide-up |
| 모달·드롭다운 | 부드러운 열림·닫힘 전환 |
| 선택 상태 | 배경색·테두리 색상 자연스럽게 전환 |
| 로딩 | 스켈레톤 또는 부드러운 로딩 인디케이터 |

- **전환 시간:** 기본 150~300ms
- **움직임:** 자연스러운 Ease-out 중심
- **성능:** CSS Transition·Animation 우선 사용
- **접근성:** `prefers-reduced-motion` 설정 존중
